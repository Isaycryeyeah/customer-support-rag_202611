## 为什么来源重复

检索单位为切片，原 Prompt 为每片单独分配“资料 N”。模型逐片列来源，同一文档自然重复：syn_t0108 的前四片都来自隐私说明，并非存了四份相同文档。syn_t0350 同样召回快充文档不同章节。

现在服务器按 source_path/doc_id 汇总，每篇文档只列一次，保留资料编号、章节、切片 ID。模型自己生成的来源尾部由服务器规范化；缺失或无效编号会标记，编号有效仍不保证语义支持正确。

真实 HTTP 回放中，syn_t0108 的 **5 个切片汇总为 2 篇文档**，need_human=True，工单优先级为高。syn_t0350 现走安全模板，不产生伪装成检索结果的来源列表。

## 安全内容

直接要求拔出冒烟插头可能导致触碰损坏带电部件。新模板限定仅在能够安全操作时切断电源；不能接近则远离并寻求专业处置，禁止反复插拔测试。配件兼容性和发热风险与是否达到快充功率分开说明。

参考：[Apple 电源适配器安全说明](https://support.apple.com/zh-cn/102193)、[香港机电工程署家庭电气安全手册](https://www.emsd.gov.hk/filemanager/en/content_442/A01_Hshld_Elctrcl_Sfty_Hndbk.pdf)。模拟库原始内容和 gold 未暗中改写，安全措辞修正独立留痕。
