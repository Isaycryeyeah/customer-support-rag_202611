# 正确性验收

2026-10-31，隔离环境 **56 项测试通过**，报告：`data/eval/runs/final-regressions.xml`；pip check 无冲突。依赖有弃用提示，不影响本轮验收，不能据此保证未来版本自动兼容。

| 问题 | 实现与验证 |
|---|---|
| 连接故障伪装成功 | 结构化 GenerationResult；超时、限流、空输出、截断返回 service_unavailable / HTTP 503 |
| 安全标记未约束回答 | 已识别高风险优先走确定性模板，不依赖检索或 LLM |
| 人工建议矛盾 | 最终 need_human/handoff_reason 同步响应、工单建议、日志、页面 |
| 过度拒答 | 普通退款、保修与强制赔付分开；否定、改写与注入有回归 |
| 域外问题转售后人工 | 明确域外且无高风险时说明服务范围，不生成工单；歧义请求保留原路径 |
| 来源重复 | 保留切片编号，按文档合并来源并显示章节 |
| 冒烟插座套用电池回答 | 充电器专用模板，限定安全断电条件、禁止反复插拔，补兼容性风险 |
| 空／陈旧索引 | 空候选、超大 k 处理；语料、模型与索引清单校验 |
| 旧日志迁移 | SQLite 追加迁移；反馈校验查询 ID 并保留关联 |

前端使用 Streamlit AppTest。HTTP 实测包含普通生成、无答案、安全、隐私投诉与反馈；Docker 内真实 Python SDK 获得非空回答，镜像不存在 .env 文件。故障分支用可控替身验证，避免主动破坏服务。

四条人工反馈已原样留存并完成在线回放。这些是已知用例回归，不是盲测或修改后人工评分，见 [反馈报告](human_feedback_report.md)。

规则仍有表达覆盖边界。冻结 test_v2 的风险组件识别为 7/10；不能用 56 项确定性测试宣称开放问题安全准确率 100%。
