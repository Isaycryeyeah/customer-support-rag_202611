# 维修费用参考说明

## 费用报价原则

具体维修费用需以设备实际检测结果为准，客服和售前渠道公布的价格仅作参考区间，不能作为最终报价承诺。

## 常见维修项目参考区间（非最终报价）

| 维修项目 | 适用产品 | 参考费用区间 |
|---|---|---|
| 屏幕总成更换 | 手机 / 平板 | 300～1200 元 |
| 电池更换 | 手机 / 平板 | 100～300 元 |
| 充电接口维修 | 手机 / 平板 | 100～250 元 |
| 键盘更换 | 笔记本 | 200～500 元 |
| 屏幕总成更换 | 笔记本 | 800～2500 元 |
| 主板维修 | 笔记本 | 500～3000 元 |

以上价格为参考区间，具体费用受机型、故障复杂度、零件供应等因素影响，最终以检测中心出具的正式报价为准。

## 费用确认流程

维修费用需在检测完成后，通过官方渠道向用户展示正式报价，用户确认后才会进行收费维修，未经用户确认不会直接收费维修。
