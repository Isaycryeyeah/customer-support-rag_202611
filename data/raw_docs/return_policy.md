# 退货政策

## 七天无理由退货

用户自收到商品之日起 7 天内，商品无质量问题、保持完好（包装、配件、赠品齐全，无明显使用痕迹）的情况下，可申请无理由退货。

超过 7 天后，无理由退货申请将不再受理，但如存在质量问题，可按保修政策或换货政策处理。

## 退货流程

1. 在官方渠道提交退货申请，说明退货原因；
2. 客服审核订单信息和退货条件；
3. 审核通过后，用户按指引寄回商品；
4. 官方收到商品并验货后，原路退款。

退款到账时间根据支付渠道不同，通常为验货通过后 3～7 个工作日内。

## 不支持无理由退货的情况

以下情况通常不支持七天无理由退货：

- 商品已拆封使用且存在明显使用痕迹（如屏幕划痕、机身磕碰）；
- 赠品、配件缺失或损坏；
- 定制化商品（如刻字、定制配置）。

## 退货审批说明

退货申请需经过官方审核，客服不能在未审核的情况下直接承诺退款，具体是否退款以验货结果为准。
